# Final_Year_Project_7Group

## Cozmoの机上走行

Windowsで `python main.py` を実行します。接続先のWi-Fi名は `cozmo_app.py` の `COZMO_SSID` に設定します。

1. **マッピング**。長方形の机の中央付近で、Cozmoを最初に測る辺へほぼ直角に向け、開始位置と向きに印を付けます。段差センサーが縁を検知できるように落下防止ガードを設置し、走行を見守ってください。基準辺を②→①→③の順で計測し、その直線を基準に残りの3辺を④→⑤→⑥の順で計測します。完了時に既存形式のJSONが `data/roaming_maps/` に自動保存されます。マップ画面で推定した4辺と寸法を確認し、QまたはEscで終了します。途中で中止した計測は保存されません。
2. **実走行試験**。学習マップが複数ある場合は、使うJSONを番号で選びます。Cozmoをそのマップの開始位置と向きに合わせ、Enterを押します。前進中に段差センサーが反応したら、直前に走った範囲で後退し、その場で旋回して走行を再開します。4辺の推定がそろった長方形の机のマップが必要です。

接続後、`Cozmo Camera` ウィンドウの映像下にある `ON` または `OFF` をクリックすると走行を開始します。走行中も同じボタンで切り替えられます。OFFの間は映像配信、物体検知、ArUco検知が停止し、走行とマップ表示は続きます。

実走行では、学習マップから進行方向で最初に交わる辺を調べます。その辺から90 mm以内で、辺と進行方向の角度が25度未満なら、一時停止して約35度で入る向きに補正し、前進を再開します。実走行中の検知点はマップ画面に表示します。学習JSONは読み取り専用です。

起動時の位置合わせは机に付けた印が基準です。以前のJSONでは、マッピング時の最初の直進から向きを推定します。別の机を使う場合や開始位置・向きが分からない場合は、マッピングからやり直してください。

6点計測では、段差を検知する直前と直後の中間位置にセンサーの前方オフセットを加えて、縁の位置を推定します。前方オフセットの初期値は添付プログラムと同じ暫定値の17.5 mmで、`algorithm/mapping/measurement_motion.py` で調整できます。
